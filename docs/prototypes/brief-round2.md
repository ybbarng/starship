# 2차 시안 "트인 함교" 지시서 (2026-10-25)

먼저 `docs/prototypes/direction-round2.md`(사용자 피드백과 밑에 깔린 방향)를 읽는다. 1차 공통 지시서 `docs/prototypes/brief.md`의 "쓸 수 있는 부품"·"끝내기 전에(확인)"도 그대로 따른다. 1차 시안 다섯 개(`src/protos/*`)는 좋은 부품 창고다. 가져다 쓰거나 고쳐 써도 된다.

뼈대는 이미 있다: `src/protos/open-bridge/OpenBridge.tsx`가 전체 화면 창밖(`SpaceView` — 끌어서 둘러보기, 천체·이름표를 눌러 날아가기)을 깔고, 스크롤 저항을 넘기면 창밖이 위쪽 30% 띠로 줄며 내부 장면이 나온다. 두 층을 채운다.

- 조종석 층: `src/protos/open-bridge/cockpit/` (진입점 `Cockpit.tsx`, props는 지금 파일 그대로)
- 내부 층: `src/protos/open-bridge/interior/` (진입점 `Interior.tsx`, props 그대로)

`OpenBridge.tsx`는 고치지 않는다(필요하면 보고에 적는다). 서로의 폴더도 고치지 않는다.

## 새로 쓸 수 있는 엔진 기능

- `useTelemetry()` (`@/sky/useTelemetry`): `{ position, earthKm, altitudeKm, speedKmS, remainingKm, traveling, progress, view: {ra, dec, lon, lat}, cursor }` — 초당 6번 갱신. 실제 궤도로 계산한 값이다.
- `useKoreaTime()` → `{ time: "15:42:07", date: "10월 25일 (일)" }`
- `@/sky/telemetry`: `formatDistance(km)`, `formatLightTime(km)`(지구까지 빛이 가는 시간 = 교신 지연), `formatSpeed(kmPerS)`(광속의 n배), `formatRA(deg)`, `formatDec(deg)`, `STAR_LY`, `REAL_RADIUS_KM`
- `<SpaceView grid />`는 적도 좌표 격자. 지금 뼈대에는 꺼져 있다. 켜고 끄는 단추가 필요하면 보고에 적어 달라(뼈대에 prop을 이어 주겠다).
- 행성은 사진 텍스처, 지구는 실제 자전 각도와 구름.

## 조종석 층 (cockpit)

**평소엔 우주가 주인공.** 창틀·큰 계기판 없이 화면 가장자리에 얇은 것들만:

1. **항법 계기(왼쪽 위, 작게)**: 지금 목적지 이름, 지구까지 거리, 교신 지연(빛 시간), 한국 시각과 날짜, 보는 방향(적경·적위 / 황경·황위), 마우스가 가리키는 좌표. 이동 중에는 **속도계**(바늘이나 막대 + `광속의 n배` 글)와 남은 거리, 진행 막대. 접기 단추로 한 줄로 줄일 수 있다.
2. **행성 단추 줄(아래 가운데)**: 1차 4번처럼 전경·수성~해왕성 + "더 먼 곳…"(목적지 모달 `DestinationPicker`). 천체를 직접 눌러도 날아간다는 것을 작은 글로 알려 준다.
3. **일 신호 띠(아래 왼쪽, 한 줄)**: "내 차례 3 · 교신 2"와 가장 급한 일의 첫 줄만, 기다린 시간. 업무/개인 색 점. 누르면 할 일 패널이 열린다. 일이 0개면 "조용함" 한 마디.
4. **할 일 패널(접힘이 기본)**: 지금 할 일(누가·무엇을·얼마나·버튼 `TaskActions`) + 다음 차례 목록 + 새 일. **접기·펼치기·크기 조절**(가장자리를 끌어서), 열린 상태와 크기는 `localStorage`에 기억(try/catch). 단축키 하나(예: `T`)로 여닫는다.
5. **교신 신호(오른쪽 가장자리)**: 사람이 부르면 화면을 덮지 않고 오른쪽 가장자리에 작은 칩이 조용히 깜빡인다(보낸 이 · 한 줄). 칩을 누르면 **"교신 수신 중" 화면**(1차 1번 `src/protos/classic/HailScreen.tsx`·`Bridges.tsx`의 출처별 함교 화상 창을 가져와 다듬어 쓴다)이 오른쪽에 열리고, 거기서 할 일 버튼으로 답한다. 여러 통이면 그 안에서 넘긴다. 데모는 75초마다 새 교신이 온다.
6. **승무원·계기 등**: 작은 단추로 여는 접히는 패널(승무원 목록과 상태, `gauges`). 평소엔 보이지 않는다.

지킬 것:
- **글은 모두 드래그해 선택·복사된다.** `select-none` 금지. 패널 위 드래그는 글 선택, 빈 하늘 드래그는 둘러보기.
- 패널 안 스크롤 영역에는 `data-scroll-inside`를 붙인다(스크롤 장면 전환과 부딪히지 않게).
- 3초 원칙: 열자마자 일 신호 띠만 봐도 "무엇이 기다리는지"는 읽힌다.
- 이벤트(`EventLayer`)는 뼈대가 이미 창밖에 깔았다.

## 내부 층 (interior)

**정말 우주선 내부처럼, 구조화해서.** 화면 위 30%는 창밖 띠(뼈대가 그린다), 그 아래 70%에 우주선 단면도:

1. **갑판 넷**, 위에서 아래로: **함교·통신실**(내 자리: 조종석 축소판과 통신 콘솔, 여기서 조종석으로 돌아간다) → **업무 모듈**(업무 프로젝트 선원 자리) → **거주 모듈**(개인 프로젝트 선원 자리, 침상·주방 같은 생활감) → **기관실·도킹 베이**(엔진, 그리고 교신선이 붙는 도킹 포트).
2. 갑판마다 이름표·갑판 번호, 칸막이 벽, **복도·사다리·해치**로 이어진 실제 같은 구조. 배관·환기구·계기 같은 세부로 "우주선 안" 느낌. 선체 바깥 윤곽(곡면 벽, 리벳, 창)이 단면을 감싼다.
3. **선원(프로젝트)**: 자기 자리(콘솔·책상)에 `Animal`로 앉아 있다. 일함=작업, 나를 기다림=자리에서 일어나 복도 쪽을 보고 손짓 + 첫 줄 말풍선, 쉼=침상(거주 모듈) 또는 휴게석, 자리 비움=빈 자리. 위치·자세로 해석 없이 읽히게.
4. **도킹 베이**: 사람이 부른 교신선(1차 3번 `src/protos/docking/ships.tsx`의 출처별 배)이 포트에 붙어 있다. 포트를 누르면 **해치가 열리는 연출**(1차 3번 `HatchModal`을 가져와 다듬는다)과 메시지·할 일 버튼. 큰 연출은 여기서만.
5. 선원이나 자리를 누르면 옆 서랍에 브리핑·할 일 체크(체크=치우기)·창으로 가기. 글은 선택·복사된다.
6. 승무원 30명(`?demo=busy`)이면 모듈 안 자리가 늘어나거나 접힌다("+n").

## 확인

- 데모 서버는 `http://127.0.0.1:7792`(dev)에 떠 있다. 7790은 사용자가 보는 서버이니 건드리지 않는다.
- `scripts/shoot.mjs`로 첫 화면, 전환 뒤(`--scroll 900`), 빈 화면(`?demo=empty&reset=1`), 많은 화면(`?demo=busy&reset=1`)을 찍어 보고, 버튼·패널 여닫기·교신 열기·해치 열기·목적지 이동을 실제로 눌러 본다. 글 선택이 되는지는 `page.mouse`로 드래그한 뒤 `window.getSelection().toString()`이 비지 않는지로 확인한다(스크립트를 스크래치 폴더에 따로 써도 된다).
- 커밋하지 않는다. 끝나면 만든 파일, 구성 한 줄, 확인한 것, 못 한 것, 뼈대에 바라는 것을 7줄 안으로 보고한다.
