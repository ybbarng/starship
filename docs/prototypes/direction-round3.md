# 3차 방향: 조종석이 메인, 우주 감상은 들어가는 곳 (2026-10-25)

## 피드백 (2차 "트인 함교"를 보고)

- "지금은 너무 우주 보는 기능에 치중한 느낌이다."
- "이 전체 화면도 마음에 든다. 근데 이게 메인이 되지 않으면 좋겠다. 계기판에서 보이는 유리창에 '확대'라든지 '우주 감상하기' 같은 걸 누르면 이렇게 크게 보이면 좋겠다."

## 읽은 것

1차는 일이 너무 앞에 나섰고(정신없음), 2차는 우주가 너무 앞에 나섰다(일이 손님이 됨). 사용자가 바라는 건 둘의 **자리 배분**이다.

- **평소 = 일하는 조종석.** 계기판이 주인공이고, 넓게 트인 유리창 너머로 우주가 늘 흐른다. 우주는 배경이자 분위기, 일은 손 닿는 곳.
- **감상 = 들어가는 곳.** 유리창의 "우주 감상하기"를 누르면 유리가 화면 가득 넓어지며 2차의 트인 함교로 들어간다(둘러보기·날아가기·속도계·좌표). Esc나 버튼으로 나오면 다시 계기판이 올라온다. 두 모드 사이 전환은 "창으로 몸을 기울인다 / 의자에 다시 앉는다" 느낌으로 이어진다.
- **3초 원칙은 계기판에서 지킨다.** 지금 할 일 하나(누가·첫 줄·기다린 시간 + 버튼 두세 개)는 계기판 한가운데 늘 보인다. 다음 차례·전체 목록·교신 내용은 펼칠 때만(1차 "정신없다" 교훈).
- **우주와 일이 서로 이어진다.** 일이 쌓이면 계기판 경고등, 교신이 오면 수신등, 감상 중에도 급한 일은 가장자리에 조용히. 선원이 부르면 내부 단면 그 자리에 불.
- 2차에서 좋았던 것(사실적인 지구, 진짜 계측 값, 글 복사, 네 갑판 단면, 1차의 교신 화상 창)은 그대로 쓴다.

## 시안

- 새 주소 `/proto/cockpit` ("조종석과 감상창"). 2차 `/proto/open-bridge`는 비교용으로 남긴다.
- 감상 모드는 2차 조종석 층(`src/protos/open-bridge/cockpit/`), 내부는 2차 내부 층(`src/protos/open-bridge/interior/`)을 가져다 쓴다.
