# 우주선 조종석 채점 기준 (아이디어를 보기 전에 정함, 2026-10-25)

사용자 구상(`brief.md`)과 비서 대시보드 1~3차에서 얻은 교훈을 기준으로 옮겼다.
3차 교훈: 은유 그림은 해석이 필요해 애매했다. **지금 할 일 하나가 글로 보이고 바로 누를 버튼**이 있어야 한다.

감점

- 정보가 그림 해석에 기대면 −5 (그림은 크기·위치·불빛 켜짐·캐릭터가 나를 보며 손짓처럼 바로 읽히는 것만)
- 이벤트·애니메이션이 지금 할 일을 가리거나 흐트러뜨리면 −3
- 프로젝트 20개 이상, 할 일 0개에서 무너지면 −3
- 업무/개인 구분이 안 보이면 −2

합치기와 다양성: 같은 구조는 하나로 합친다(id를 `·`로 잇는다). 상위 5개는 서로 다른 방향을 대표하도록, 점수가 비슷하면 다른 구조를 고른다.
