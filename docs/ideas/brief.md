# 우주선 조종석 아이디어 브리프 (2026-10-25)

개인 AI 비서 대시보드를 "거대한 우주선 내부" 웹앱으로 새로 만든다. 이 앱은 화면만 맡고, 데이터와 동작은 비서 서버 API를 쓴다.

## 비서 서버가 주는 것

- 받은편지함 `pending`: 할 일 항목. `kind`는 question(질문)·permission(권한)·input(입력 대기)·reply(세션이 답을 마치고 내 차례)·alert(경보)·mention(부름)·review(리뷰)·todo(날짜 할 일). 항목마다 `project`, `context`(work|personal), `text`(첫 줄이 요지), `since`(기다린 시각), `url`, `sessionId`.
- 프로젝트 20여 개: 이름, 업무/개인, 세션 상태(working 일하는 중 · turn/waiting 내 차례 · idle 쉼 · 없음), 창이 열려 있는지(windowed), 브리핑(요약·오늘 할 일·다음·나를 기다리는 것·위험), 열린 PR, 마지막 커밋.
- 동작: 그 세션의 tmux 창으로 이동(focus), 항목 치우기(dismiss), 열기(open), 브리핑 다시 만들기(brief).
- Slack·Linear·Confluence에서 나를 부른 메시지는 아직 일부만 들어온다(Linear·GitHub 일부). 시안에서는 지어낸 예시를 섞는다.

## 사용자 구상 (원문 요지)

- 전체 테마는 거대한 우주선 내부.
- **첫 화면**: 스크롤하지 않은 화면을 가득 채우는 조종석.
  - 위쪽 절반의 대부분은 창밖 우주. 태양계, 각 행성, 위성, 위에서 본 태양계(실제 스케일이면 안 보이니 적당히), 유명한 별, 혜성, 소행성 등 원하는 목적지로 이동하며 여행한다. 배경 별은 실제 배치를 따르고 별자리 선, 별·행성 이름표. 정말 우주를 여행하는 느낌.
  - 가끔 재미난 이벤트: 외계인이 지나간다든지, 우주와 관련된 것들. (공개 저장소라 영화·드라마 속 캐릭터는 쓰지 않고, 직접 지어낸 외계인과 실제 우주 현상으로 만든다)
  - 필요한 기능은 화면 위 모달로 띄워 보고 닫는다.
  - Slack·Linear·Confluence 등에서 누가 나에게 메시지를 보냈으면, 다른 우주선이 교신해 오며 메시지를 보내는 것처럼.
  - 아래쪽은 계기판: 상태를 파악하고 조절해야 하는 조명과 버튼.
- **스크롤을 내리면** (약간의 저항을 넘겨): 조종석이 전체적으로 작아지며 우주선 내부 전경이 보이고, 내 조종석은 그 안의 작은 부분으로 아주 간략하게만 보인다. 우주선 위쪽 1/3 정도에 아까의 창밖이 작게, 나머지에서 각 프로젝트와 세부적으로 상호작용하고 할 일을 체크한다. 더 창의적인 것도 좋다. 프로젝트는 각자 자리에 앉은 우주선원(동물이면 귀엽다).

## 지난 시안에서 얻은 교훈 (꼭 지킨다)

- 1·2차: 은유 그림(강아지가 문 공, 혜성 꼬리, 녹는 아이스크림)만으로 정보를 맡기면 해석이 필요해 애매했다.
- 3차: 열자마자 3초 안에 **지금 할 일 하나**(누가·무엇을 질문 첫 줄까지 글로·얼마나 기다렸나)와 **바로 누를 버튼**(창으로 가기·답하기·1시간 뒤·치우기·비서에게)이 필요하다. 다음 차례 2~3개도 글로.
- 그림은 크기·위치·불빛 켜짐·캐릭터가 나를 보며 손짓처럼 해석 없이 읽히는 것만 정보를 맡는다. 우주 테마는 배경과 옷.

## 조건

- 로컬에서만 쓰는 Next.js 웹앱. Canvas 2D·SVG·WebGL(three.js/react-three-fiber) 모두 쓸 수 있다. 시안 하나를 하루 안에 만들 수 있어야 한다.
- 외부 자료(별 목록, 텍스처, 소리, 폰트)는 라이선스가 분명한 것만. 적을수록 좋다. 영화·드라마 속 캐릭터와 작품은 쓰지 않는다.
- 회사 내용은 화면에서 API로만 받아 그린다.

## 출력

지정받은 파일에 JSON 배열 25개. 항목마다:

```json
{
  "id": "A01",
  "title": "짧은 이름",
  "pitch": "한두 문장 컨셉",
  "cockpit": "첫 화면 구성: 창밖·계기판·모달이 어디에 어떻게",
  "now": "지금 할 일 하나가 어떻게 글로 보이고 버튼이 어디 있나, 다음 차례는 어디",
  "comms": "외부 메시지가 다른 우주선 교신으로 어떻게 오고 어떻게 답하러 가나",
  "voyage": "창밖 여행: 목적지 고르기, 이동 연출, 사실성(별·별자리·이름표)",
  "events": "가끔 일어나는 이벤트 1~3개",
  "interior": "스크롤 전환과 우주선 전경, 선원(프로젝트)과의 상호작용, 할 일 체크",
  "tech": "구현 방법과 필요한 외부 자료",
  "why": "이 안이 특별한 이유 한 문장"
}
```

모든 글은 일상 한국어로, 항목당 500자 안팎. 25개가 서로 다른 구조여야 한다(이름만 다른 변형 금지).
