# 창밖 축척

태양계를 실제 비율 그대로 그리면 화면에 담기지 않는다. 지구를 1픽셀로 그려도 해왕성은 3백만 픽셀 넘게 떨어진다.
그래서 크기와 거리를 따로, 한 가지 규칙씩으로 줄인다. 값은 `src/sky/astro.ts`의 `SCENE_SCALE`에 있다.

## 규칙

- **크기**: 지구 반지름을 0.5칸으로 두고 모든 행성·위성을 실제 비율로 그린다(목성은 지구의 11배, 달은 0.27배).
  - 너무 작아 보이지 않는 천체(포보스·베스타·엔켈라두스)는 최소 크기 0.03칸으로 키운다.
  - 태양만 예외로 실제 비율의 1/3이다. 그대로면 수성 궤도가 태양 안으로 들어간다.
  - 탐사선(보이저)은 실제 크기로는 보이지 않아 따로 크게 그린다.
- **거리**: 태양에서 거리가 두 배가 될 때마다 100칸씩 멀어진다(로그). 방향은 실제 그대로다.
  - 화면 거리 = 100 × log₂(1 + 실제 거리 AU ÷ 0.3). 0.3을 더해 태양 가까이에서 무너지지 않게 했다.
  - 지구 212칸, 목성 420칸, 해왕성 666칸, 보이저 1호 약 917칸.
- **위성 거리**: 모행성 반지름 단위로 같은 방식(두 배마다 반지름 하나)으로 줄인다. 달은 지구 반지름 60배 거리지만 화면에서는 6.9배다.
- **멀리 있는 천체**: 화면에서 반지름이 14픽셀보다 작으면 원반 대신 빛점으로 보인다. 맨눈으로 보는 이웃 행성이 별처럼 점으로 보이는 것과 같다.
  공기가 없어 흐려지지는 않지만, 멀리 있으면 원반 모양과 고리는 보이지 않는다.

## 화면에 알리기

- 조종석 유리 아래 계측 줄과 감상 모드 행성 단추 위에 "축척 · 크기 실제 비율 · 거리 두 배마다 한 칸"을 작게 적는다. 마우스를 올리면 규칙 전체를 보여 준다.
- 계기판의 거리·빛 지연·속도는 줄이지 않은 실제 값이다(`src/sky/telemetry.ts`).
