# 문서 목차

처음 받아 띄우는 법과 환경 변수는 저장소 맨 위 [README](../README.md)에 있다. 여기는 문서마다 무엇을 정했는지 한 줄씩 적는다.

## 데이터 형식(남과 맞추는 약속)

- [protocol.md](protocol.md) — 본부와 주고받는 프로토콜 `starship/1`: 스냅숏·동작·지도·책상·사용 한도 끝점, 틀린 항목만 빼는 규칙.
- [desk.md](desk.md) — 선실 책상 형식 `starship-desk/1`: 세션이 나를 기다리는 것(고르기·확인·승인·질문)과 지금 하는 일, 답하는 법.
- [map.md](map.md) — 프로젝트 지도 형식 `starship-map/1`: 저장소 안 `map.json`의 구역·상태·갈림길·교신과 찾는 순서.

## Starship 서버가 직접 하는 일

- [usage.md](usage.md) — 연료 기록·연료실: Claude Code 기록을 컴퓨터를 붙잡지 않고 이어 읽는 규칙, 영역 나누기, 주간 연료.
- [files.md](files.md) — 책상 카드의 파일 보기·열기와 PWA: 허용 폴더, 숨김·실행 파일 거절, 이 컴퓨터 안에서만 여는 규칙, md 보기 화면.
- [secure.md](secure.md) — 보안 구역: AI 세션의 1Password 신청서와 호출 기록, 빨간 표시와 확인함, 값 보호와 이름 가림, 비서 기록을 데모와 섞지 않는 규칙.

## 화면

- [hq.md](hq.md) — 본부 방 설계안(사용자 결정 기다림): 비서의 할 일·나르기·시설·지도 판, 나르기 기록 형식 `starship-relay/1`과 저장 위치.
- [cockpit-inbox.md](cockpit-inbox.md) — 조종석 결재함: 승무원별로 묶어 펼치기, 마지막 답변 접기, 코드 리뷰 칸, 키보드 처리.
- [crew-views.md](crew-views.md) — 승무원을 보는 세 화면(결재함·승무원 정보·선실)의 역할 나누기.
- [frontier.md](frontier.md) — 선실 가운데 그림인 육각 개척지: 끌고 확대하는 카메라, 확대 단계마다 보이는 글.
- [sky-3d.md](sky-3d.md) — 창밖 3D 별하늘: 별 자료, 다른 별로 갔을 때 별자리가 일그러지는 계산.
- [scale.md](scale.md) — 창밖 태양계 축척: 크기는 실제 비율, 거리는 로그로 줄이는 규칙.
- [pace.md](pace.md) — 그리는 박자: 하루 종일 켜 둬도 가볍게 움직일 때만 자주 그리는 규칙.

## 자료·기록

- [ASSETS.md](ASSETS.md) — 들인 외부 자료(별 자료·글꼴)의 출처와 라이선스.
- [ideas/](ideas/) — 조종석 아이디어 100개와 채점(`scores.md`, 기준 `criteria.md`). [ideas/cabin/](ideas/cabin/)은 선실 지도 시안 아이디어.
- [prototypes/](prototypes/) — 고른 아이디어를 시안으로 만들 때의 지시서(`brief*.md`)와 차수마다 피드백을 정리한 방향(`direction-round*.md`). 지난 기록이라 지금 화면과 다를 수 있다.
